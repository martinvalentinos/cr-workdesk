# Public repository security

Only application source and synthetic tests are allowed in this repository.

Do not commit company workbooks, private CR records, exports, screenshots of business data, SharePoint links, credentials, tokens or environment files. Deleting a file from a commit does not erase public Git history.

GitHub Pages is publicly accessible. Connecting live corporate data requires tenant authorization, appropriately scoped Microsoft Entra delegated permissions and an independent security review. Microsoft Graph is disabled in this published bootstrap by blank configuration.
